Statistik Deskriptif
AVERAGE · MEDIAN · MODE · STDEV · VAR
▼

Statistik deskriptif digunakan untuk meringkas dan menggambarkan data. Ini adalah fondasi utama analisis data di Excel.

FungsiKegunaanContoh Formula
=AVERAGE()Rata-rata aritmatika=AVERAGE(A1:A10)
=MEDIAN()Nilai tengah data=MEDIAN(A1:A10)
=MODE.SNGL()Nilai paling sering muncul=MODE.SNGL(A1:A10)
=STDEV.S()Standar deviasi sampel=STDEV.S(A1:A10)
=STDEV.P()Standar deviasi populasi=STDEV.P(A1:A10)
=VAR.S()Varians sampel=VAR.S(A1:A10)
=SKEW()Kemiringan distribusi=SKEW(A1:A10)
=KURT()Keruncingan (kurtosis)=KURT(A1:A10)
💡 Tips: Gunakan =STDEV.S() untuk data sampel (sebagian data), dan =STDEV.P() untuk data populasi (seluruh data). Perbedaannya ada di pembagi: sampel ÷(n-1), populasi ÷n.
⚠️ Perhatian: MODE.SNGL hanya mengembalikan satu modus. Jika data bimodal, gunakan MODE.MULT dengan Ctrl+Shift+Enter (array formula).

Ukuran Posisi & Distribusi
PERCENTILE · QUARTILE · RANK
▼

Ukuran posisi membantu kita memahami di mana suatu nilai berada relatif terhadap data lain.

FungsiKegunaanContoh Formula
=PERCENTILE.INC()Persentil ke-n (0–1)=PERCENTILE.INC(A1:A10, 0.75)
=QUARTILE.INC()Kuartil Q1/Q2/Q3=QUARTILE.INC(A1:A10, 1)
=RANK.AVG()Peringkat suatu nilai=RANK.AVG(B1, A1:A10)
=GEOMEAN()Rata-rata geometrik=GEOMEAN(A1:A10)
=HARMEAN()Rata-rata harmonik=HARMEAN(A1:A10)
=TRIMMEAN()Rata-rata terpangkas=TRIMMEAN(A1:A10, 0.1)
💡 Kuartil: Masukkan angka 1 (Q1), 2 (Q2=median), atau 3 (Q3) pada argumen kedua. Q1–Q3 digunakan untuk menghitung IQR = Q3 − Q1.

Distribusi Normal
NORM.DIST · NORM.INV · STANDARDIZE
▼

Distribusi Normal (bell curve) adalah distribusi paling penting dalam statistik. Digunakan untuk probabilitas, interval kepercayaan, dan uji hipotesis.

FungsiKegunaanContoh Formula
=NORM.DIST()P(X ≤ x) — nilai kumulatif=NORM.DIST(75, 70, 10, TRUE)
=NORM.INV()Nilai x dari probabilitas p=NORM.INV(0.95, 70, 10)
=NORM.S.DIST()Distribusi normal standar (Z)=NORM.S.DIST(1.96, TRUE)
=NORM.S.INV()Nilai Z dari probabilitas=NORM.S.INV(0.975)
=STANDARDIZE()Konversi X ke nilai Z=STANDARDIZE(75, 70, 10)
💡 TRUE vs FALSE: Argumen terakhir TRUE = kumulatif (luas di bawah kurva dari −∞ sampai x). FALSE = nilai densitas (tinggi kurva di titik x).
🔑 Rumus Z: Z = (X − μ) / σ. Nilai Z = 1.96 artinya 97.5% data berada di bawahnya (distribusi normal standar).

Distribusi t, Chi-Square & F
T.DIST · CHISQ.DIST · F.DIST
▼
FungsiKegunaanContoh
=T.DIST()Distribusi t (ekor kiri)=T.DIST(2.5, 9, TRUE)
=T.DIST.2T()Distribusi t (dua ekor)=T.DIST.2T(2.5, 9)
=T.INV.2T()Nilai kritis t (dua ekor)=T.INV.2T(0.05, 9)
=CHISQ.DIST()Distribusi Chi-square=CHISQ.DIST(5.99, 2, TRUE)
=CHISQ.INV()Nilai kritis chi-square=CHISQ.INV(0.95, 2)
=F.DIST()Distribusi F=F.DIST(3.5, 5, 20, TRUE)
=F.INV()Nilai kritis F=F.INV(0.95, 5, 20)
💡 df = degrees of freedom (derajat kebebasan). Untuk sampel n data, df biasanya = n−1. Distribusi t digunakan saat σ tidak diketahui atau n kecil (n < 30).

Distribusi Diskrit
BINOM.DIST · POISSON.DIST · HYPGEOM
▼
FungsiKegunaanContoh
=BINOM.DIST()P(X=k) binomial=BINOM.DIST(3, 10, 0.5, FALSE)
=BINOM.DIST()P(X≤k) kumulatif=BINOM.DIST(3, 10, 0.5, TRUE)
=POISSON.DIST()Distribusi Poisson=POISSON.DIST(3, 2.5, FALSE)
=HYPGEOM.DIST()Hipergeometrik=HYPGEOM.DIST(2, 5, 10, 20, FALSE)
=NEGBINOM.DIST()Binomial negatif=NEGBINOM.DIST(5, 3, 0.4, FALSE)
💡 Binomial: =BINOM.DIST(k, n, p, FALSE) di mana k = kejadian sukses, n = jumlah percobaan, p = peluang sukses.
🎯 Poisson: Digunakan untuk menghitung peluang kejadian dalam interval waktu/ruang tertentu. Lambda (λ) adalah rata-rata kejadian per interval.

Uji Hipotesis & Korelasi
T.TEST · CORREL · SLOPE · RSQ
▼
FungsiKegunaanContoh
=T.TEST()p-value uji t=T.TEST(A1:A10, B1:B10, 2, 1)
=Z.TEST()p-value uji Z=Z.TEST(A1:A10, 50)
=F.TEST()Uji kesamaan varians=F.TEST(A1:A10, B1:B10)
=CHISQ.TEST()Uji chi-square=CHISQ.TEST(aktual, harapan)
=CORREL()Korelasi Pearson (r)=CORREL(A1:A10, B1:B10)
=SLOPE()Koefisien regresi b₁=SLOPE(B1:B10, A1:A10)
=INTERCEPT()Konstanta regresi b₀=INTERCEPT(B1:B10, A1:A10)
=RSQ()Koefisien determinasi R²=RSQ(B1:B10, A1:A10)
💡 T.TEST argumen: tails (1=satu ekor, 2=dua ekor), type (1=berpasangan, 2=dua sampel sama variansi, 3=dua sampel beda variansi).
🔑 Interpretasi R²: Nilai R² mendekati 1 berarti variabel X dapat menjelaskan variabel Y dengan baik. Contoh: R²=0.85 artinya 85% variasi Y dijelaskan oleh X.
