🤔 Apa itu Linked List?

Linked List adalah struktur data linear yang terdiri dari node-node yang saling terhubung melalui pointer.

Karakteristik Utama:

  • Setiap node menyimpan data dan pointer ke node berikutnya
  • Ukuran dinamis - bisa bertambah/berkurang saat runtime
  • Tidak memerlukan memory yang berurutan
  • Node pertama disebut HEAD
  • Node terakhir menunjuk ke NULL

🔧 Struktur Node dalam C++

Node adalah building block dari linked list. Setiap node memiliki 2 komponen:

1️⃣ Data

Menyimpan nilai/informasi

2️⃣ Pointer Next

Menunjuk ke node berikutnya

struct Node {
    int data;       // Menyimpan nilai
    Node* next;     // Pointer ke node berikutnya
};

💡 Contoh Membuat Node:

// Membuat node baru
Node* newNode = new Node();
newNode->data = 10;
newNode->next = nullptr;

➕ Operasi INSERT

1. Insert di Awal (Head)

void insertAtHead(Node*& head, int value) {
    Node* newNode = new Node();
    newNode->data = value;
    newNode->next = head;
    head = newNode;
}
// Time Complexity: O(1)

2. Insert di Akhir (Tail)

void insertAtTail(Node*& head, int value) {
    Node* newNode = new Node();
    newNode->data = value;
    newNode->next = nullptr;
    
    if (head == nullptr) {
        head = newNode;
        return;
    }
    
    Node* temp = head;
    while (temp->next != nullptr)
        temp = temp->next;
    temp->next = newNode;
}
// Time Complexity: O(n)

📢 Script: "Mari kita bahas operasi paling dasar: INSERT atau menambah data. Ada dua cara utama. Pertama, insert di awal atau head - ini sangat efisien dengan kompleksitas O(1) karena kita hanya perlu membuat node baru dan menghubungkannya ke head lama. Kedua, insert di akhir atau tail - ini membutuhkan waktu O(n) karena kita harus traversal dari head sampai node terakhir. Perhatikan perbedaan kode keduanya di layar."

➖ Operasi DELETE

1. Delete dari Awal

void deleteFromHead(Node*& head) {
    if (head == nullptr) return;
    
    Node* temp = head;
    head = head->next;
    delete temp;
}
// Time Complexity: O(1)

2. Delete by Value

void deleteByValue(Node*& head, int value) {
    if (head == nullptr) return;
    
    if (head->data == value) {
        Node* temp = head;
        head = head->next;
        delete temp;
        return;
    }
    
    Node* temp = head;
    while (temp->next != nullptr &&
           temp->next->data != value)
        temp = temp->next;
    
    if (temp->next == nullptr) return;
    
    Node* toDelete = temp->next;
    temp->next = temp->next->next;
    delete toDelete;
}

📢 Script: "Selanjutnya operasi DELETE. Sama seperti insert, delete dari awal sangat cepat dengan O(1) - kita hanya perlu menggeser head pointer dan menghapus node lama. Untuk delete berdasarkan nilai tertentu, kita perlu mencari node tersebut dulu, jadi kompleksitasnya O(n). Yang penting dalam delete adalah jangan lupa membebaskan memory dengan perintah delete untuk menghindari memory leak."

🔍 Operasi TRAVERSAL & SEARCH

Display/Print Linked List

void display(Node* head) {
    Node* temp = head;
    while (temp != nullptr) {
        cout << temp->data << " -> ";
        temp = temp->next;
    }
    cout << "NULL" << endl;
}
// Time Complexity: O(n)

Search Element

Node* search(Node* head, int value) {
    Node* temp = head;
    while (temp != nullptr) {
        if (temp->data == value)
            return temp;
        temp = temp->next;
    }
    return nullptr;
}
// Time Complexity: O(n)

💡 Catatan: Traversal berarti mengunjungi setiap node dari awal sampai akhir.

📢 Script: "Untuk melihat isi linked list atau mencari data tertentu, kita perlu melakukan traversal - yaitu mengunjungi setiap node satu per satu dari head sampai NULL. Fungsi display menampilkan semua data, sedangkan fungsi search mencari nilai tertentu. Kedua operasi ini memiliki kompleksitas O(n) karena dalam worst case kita harus mengecek semua node. Ini berbeda dengan array yang bisa langsung akses index tertentu."

⚖️ Array vs Linked List

Aspek Array Linked List
Memory Berurutan (contiguous) Tidak berurutan
Ukuran Tetap (fixed) Dinamis
Akses Element O(1) - Cepat O(n) - Lambat
Insert di Awal O(n) O(1)
Insert di Akhir O(1) O(n)
Delete di Awal O(n) O(1)
Memory Waste Bisa banyak jika tidak terpakai Minimal (sesuai kebutuhan)

📢 Script: "Sekarang mari kita bandingkan linked list dengan array. Keduanya punya kelebihan masing-masing. Array unggul dalam akses random dengan O(1), tapi lemah dalam insert dan delete yang memerlukan shifting data. Sebaliknya, linked list sangat cepat untuk insert dan delete di awal, tapi lambat untuk akses karena harus traversal. Array punya ukuran tetap, sementara linked list bisa berkembang dinamis sesuai kebutuhan. Tidak ada yang lebih baik mutlak - semuanya tergantung kebutuhan aplikasi kita."

✅ Kelebihan & ❌ Kekurangan

✅ Kelebihan

  • Ukuran Dinamis - bisa membesar/mengecil sesuai kebutuhan
  • Insert/Delete Efisien - terutama di awal list (O(1))
  • Memory Efficient - tidak ada memory yang terbuang
  • Implementasi Mudah - untuk stack dan queue
  • Tidak perlu reorganisasi - saat insert/delete

❌ Kekurangan

  • Akses Lambat - tidak bisa random access (harus traversal)
  • Extra Memory - untuk pointer di setiap node
  • Tidak Cache-Friendly - node tersebar di memory
  • Reverse Traversal Sulit - pada singly linked list
  • Pencarian Lambat - harus linear search O(n)

📢 Script: "Mari kita rangkum kelebihan dan kekurangan linked list. Di sisi positif, linked list sangat fleksibel dengan ukuran dinamis, operasi insert dan delete yang cepat, dan penggunaan memory yang efisien tanpa waste. Namun ada trade-off - akses data lebih lambat karena harus traversal, ada overhead memory untuk pointer, dan pencarian linear yang kurang efisien. Memahami trade-off ini penting untuk memilih struktur data yang tepat."

🎯 Kapan Menggunakan Linked List?

✅ Gunakan Linked List Ketika:

  • Ukuran data tidak diketahui atau sering berubah
  • Sering melakukan insert/delete di awal atau tengah list
  • Tidak perlu akses random/by index
  • Implementasi stack, queue, atau hash table (chaining)
  • Memory terbatas dan ingin efisien (tidak ada waste)

❌ Gunakan Array Ketika:

  • Perlu akses cepat by index (random access)
  • Ukuran data relatif tetap dan diketahui
  • Operasi utama hanya di akhir (push/pop)
  • Memory locality penting (cache performance)
  • Sering melakukan pencarian atau sorting

📢 Script: "Pertanyaan penting: kapan kita harus menggunakan linked list? Gunakan linked list ketika ukuran data tidak pasti dan sering berubah, ketika kita sering insert atau delete data di awal atau tengah, atau ketika kita implementasi struktur data seperti stack dan queue. Sebaliknya, pakai array ketika perlu akses cepat by index, ukuran data relatif tetap, atau sering melakukan pencarian dan sorting. Pemilihan yang tepat akan membuat program kita lebih efisien."
